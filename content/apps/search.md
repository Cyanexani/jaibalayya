## overview
Search looks through app names and through every notes file at once. Results link straight to the section that matched.

- Press `/` anywhere to search.
- Recent searches stay on this device.
- Hold the Search tile for voice search (in browsers that support it).

## what's new
### 0.1: first version
Search is part of the first Metro OS release.

## improved
- Classic Metro search only looked at the web. This one searches the OS's own notes too.

## removed
Nothing removed.

## coming next
- Search inside Notes, Documents and Files once they ship in phase 1.
- Search suggestions as you type.

## known issues
