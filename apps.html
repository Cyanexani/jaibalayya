Thirteen applications rebuilt around the same idea: put the content first, put the chrome last, and never make somebody learn a new place to tap. Pick a tile to look inside.

Application list

Status labels are the project's own tracking states. Available means it ships in the current preview build; In development means it is on a branch and partly working; Planned means nobody has started it yet — and that is an invitation.

Third-party apps

Everything else
still works.

Metro OS is a shell, not a walled garden. Every Android app you already use launches from the same list, gets a tile, and can adopt the system accent with a few lines of theme XML.

Every app gets a tile

Icons are wrapped into square Metro tiles with an extracted accent colour. Resize and pin them like anything else.

Opt into the theme

Read metro.accent from the theme provider and your app follows the user's colour everywhere.

Publish a live tile

One TileProvider service, one update budget. The shell schedules the rest.
