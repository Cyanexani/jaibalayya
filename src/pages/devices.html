Hardware

Metro,
wherever you are.

Metro OS is an app, so the honest answer to “does it run on my phone?” is usually yes — and the honest answer to “is it supported on my phone?” is only whatever somebody has actually tested.

The only hard rules

Requirements.

Three platform requirements, no vendor list. If your device meets them, the preview build will install; if something then misbehaves, that is a bug worth filing.

Platform

Android 11+

API 30 or newer. The shell needs the modern launcher, gesture and notification-listener APIs.

Required

Architecture

arm64-v8a

64-bit only. A 32-bit build is possible but nobody maintains one, so it is not published.

Required

Memory

3 GB RAM

Below this the shell still runs, but the tile engine drops to conservative update budgets.

Recommended

Community results

by us and you.

How it adapts

One layout,
many screens.

The tile grid is defined in columns, not pixels. A narrow device gets four columns, a wide one gets six, and the tile sizes stay square either way.

  1. Install the current preview or nightly

    A result against an old build helps nobody.

  2. Use it for a day

    Most compatibility problems are power-management problems, and those take hours to show up.

  3. Open the hardware-support template

    Device, Android version, skin, build number, and what did or did not work.

  4. Attach a screenshot if something looks wrong

    Cutouts and gesture insets are almost always easier to see than to describe.
