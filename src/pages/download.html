Compatibility

What actually
runs it.

Metro OS has no certified device list, and inventing one would be worse than useless. What exists is a set of platform requirements and a community compatibility table that anyone can add a result to.

REQUIRED

Android 11 (API 30) or newer

The shell relies on the modern launcher, notification-listener and gesture APIs.

REQUIRED

arm64-v8a · 3 GB RAM

Below that the tile engine still runs, but update budgets get aggressive.

NOT REQUIRED

Root, unlocked bootloader, custom ROM

Metro OS is an app. Set it as your launcher; set the old one back whenever you like.

Installation

Five minutes.
Reversible.

  1. Download the APK

    Take the preview build from the releases page, or a nightly from CI.

  2. Verify the checksum

    Never install a build you have not checked. The hash is published beside every release.

  3. Allow installation from your browser or file manager

    Settings → Apps → Special access → Install unknown apps.

  4. Install and set as default launcher

    Press Home once and pick Metro OS. Choosing “Always” is optional.

  5. Grant the notification listener

    This is what lets tiles show counts. Skip it and everything else still works.

Going back: Settings → Apps → Default apps → Home app. Your old launcher returns exactly as it was; Metro OS keeps nothing.
verify 
# compare against the hash on the release page
sha256sum metro-os-0.5.0-preview.apk

# or, over adb
adb install -r metro-os-0.5.0-preview.apk
adb shell cmd package set-home-activity \
  os.metro.shell/.HomeActivity

What it asks for

Home
To be your launcher
Notifications
Read counts for tiles
Contacts
People tiles and the dialler — optional
Media
Music and Photos — optional
Network
Weather only — optional, and off by default

No analytics, no crash reporting, no account, no advertising identifier. If you deny everything except Home, Metro OS still runs — the tiles just stay quiet.
