Who does what

Five kinds
of contribution.

Code is the loudest but not the largest. The translation pipeline and the device compatibility table are both community-run and both more valuable than most pull requests.

Developers

Shell, tile engine, system services and the app suite. Kotlin, Compose, and a strong opinion about back stacks.

Designers

Type ramp, icon set, motion curves and the endless argument about how wide a wide tile should be.

Testers

Nightly builds on real hardware, filed with the device, the Android version and the exact steps.

Translators

Twenty-one languages so far. Metro's large type punishes lazy translation, which keeps the bar high.

Writers

Documentation, RFCs, release notes and the install guide that stops somebody bricking an evening.

Maintainers

Review, triage and the unglamorous work of saying no to good ideas that belong somewhere else.
